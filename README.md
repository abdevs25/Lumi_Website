# Lumi's World

Open `index.html` in a modern browser, or upload the entire `tiny-friend-frontend` folder to static hosting. Keep `assets/` beside `index.html`.

## Working features
- Dedicated Lumi's Archive rock collection with an illustrated collection collage, eight selectable rock cards, stories, and the included `My_Extremely_Important_Rocks.mp3` song player with seek/progress.
- Expanded Moodlight Lab with selectable glow colours and changing Lumi dialogue.
- Bubble & Blaze lab with supplied Lumi bubble video, illustrated chilli/sparks/fire/milk states, and a two-second spark phase.
- Click sparkle trail, hero cursor response, night/day theme, optional synthesized UI sound effects, friendship choices, and expedition goodbye.

The top sound control toggles synthesized interface sound effects. The rock song has its own play/pause control in the Rock Collection. Browser autoplay restrictions mean audio begins only after a visitor clicks Play.

This is a standalone static site. It has not been connected to a backend or deployed to a live URL.
